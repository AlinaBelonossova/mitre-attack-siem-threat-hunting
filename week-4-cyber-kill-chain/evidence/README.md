# Week 4 Evidence

This directory contains evidence for the Cyber Kill Chain practical analysis.

## Recommended screenshots

Capture screenshots showing:

1. Lockheed Martin Cyber Kill Chain source with the seven stages.
2. MITRE ATT&CK SolarWinds Compromise (C0024) campaign page.
3. MITRE ATT&CK SUNBURST (S0559) page.
4. MITRE ATT&CK SUNSPOT (S0562) page.
5. The completed Cyber Kill Chain mapping table.
6. The final SIEM/threat-hunting workflow or analysis diagram.

## Evidence naming

Use descriptive names such as:

- `01-lockheed-kill-chain.png`
- `02-mitre-solarwinds-c0024.png`
- `03-mitre-sunburst-s0559.png`
- `04-mitre-sunspot-s0562.png`
- `05-kill-chain-mapping.png`
- `06-siem-threat-hunting-workflow.png`

Do not fabricate screenshots. Evidence should show the actual source or analysis performed.
